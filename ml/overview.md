# 机器学习总览

## 总比喻：训练一位不会背答案的学徒

机器学习像培养一个学徒：你给它很多带答案的例子，它调整自己的做事方式；之后给它没见过的新例子，看它能不能做对。

- 样本：一件练习题
- 特征：题目中提供的线索
- 标签：标准答案
- 模型：学徒形成的判断方法
- 参数：学徒脑中的许多可调整旋钮
- 训练：做题、对答案、修正方法
- 推理：遇到新题目时给出答案

## 三类任务

### 回归：猜一个数

例如预测房价、温度、销售额。比喻：学徒要报出一个具体价格。

### 分类：放进一个盒子

例如判断垃圾邮件或正常邮件。比喻：学徒要把物品放入有限的几个分类盒。

### 聚类：自己找小组

没有标准答案，让模型按相似程度分组。比喻：把一群陌生人按兴趣或外貌分成几桌，但事先没有人告诉你每桌叫什么。

## 训练集、验证集、测试集

比喻：训练集是平时练习题，验证集是用来选择学习方法的模拟考试，测试集是最后一次正式考试。

如果把正式考试题反复拿来练习，最后分数就不能代表真正能力。

## 过拟合和欠拟合

- 欠拟合：学徒连练习题都做不好，方法太简单
- 过拟合：学徒背下了练习题的答案，换一道题就不会
- 泛化：面对新题目仍能正确处理

机器学习追求的不是死记硬背，而是学到能迁移的规律。

## 评估指标

回归常见 MAE、MSE、RMSE；分类常见 Accuracy、Precision、Recall、F1。

比喻：评价学徒不能只看一个总分。有时“漏掉一个真正的病人”比“误报一个健康人”代价大，所以要选择适合任务的指标。

## 完整流程

```text
明确任务 → 准备数据 → 选择特征和标签 → 划分数据 → 训练 → 评估 → 分析错误 → 改进 → 部署并监控
```

真正困难的部分通常不是调用算法，而是定义任务、准备数据和理解错误。
