# 常见算法

## 1. 线性回归：一把可调的尺子

```text
y = w1x1 + w2x2 + ... + b
```

比喻：模型拿一把多刻度尺，把面积、房间数等线索按不同权重相加，得到预测价格。`w` 是每个特征的影响力，`b` 是起始偏移。

## 2. 逻辑回归：带刻度的投票器

它先计算一个分数，再把分数变成 0 到 1 的概率，常用于二分类。比喻：投票器先收集支持或反对的票，最后把总票数换成“属于某类的信心”。

## 3. 决策树：一串问题

```text
面积 > 100？
├── 是：价格可能较高
└── 否：继续问房间数？
```

比喻：像医生问诊或二十问游戏。优点是直观，缺点是单棵树可能把训练数据记得太细。

## 4. 随机森林：一群独立顾问

训练很多棵不同的决策树，再综合它们的意见。比喻：不要只问一个顾问，而是问一群背景略有不同的顾问，再进行投票，通常更稳定。

## 5. K-means：移动几个班级中心

1. 随机放置 `K` 个中心
2. 每个样本加入最近的中心
3. 每个中心移动到自己小组的平均位置
4. 重复直到基本稳定

比喻：教室里有几个班主任，学生先找最近的班主任，班主任再走到自己学生的中心位置。

## 6. K 近邻：询问附近的人

新样本到来后，找距离最近的 `K` 个样本，根据它们投票或平均。比喻：你不知道新水果是什么，就询问附近最相似的几种水果。

## 7. 选择算法前先问

1. 是预测数字、类别，还是自动分组？
2. 数据是表格、图像、文本还是时间序列？
3. 是否需要解释？
4. 数据量多大？
5. 哪类错误代价最高？
