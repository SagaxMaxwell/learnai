# LearnAI 学习路线

从数学和 Python 出发，逐步理解模型原理，再进入 LLM 应用工程。先看 `README-map.md`。

这套资料从你已经熟悉的 Python 基础出发，目标是逐步理解：

```text
数学与数据表示 → 机器学习 → 深度学习与大语言模型 → RAG / Tool / MCP / Agent / Skill
```

## 目录

- `basics`：函数、向量、矩阵、概率、损失和梯度
- `ml`：回归、分类、聚类、训练和评估
- `deep-learning`：神经网络、Token、Embedding、Attention、Transformer
- `llm-engineering`：Prompt、RAG、工具调用、MCP、Workflow、Agent、Skill

## 推荐顺序

1. `README-map.md`
2. `basics/math-data.md`
3. `ml/overview.md`
4. `ml/algorithms.md`
5. `deep-learning/neural-networks.md`
6. `deep-learning/token-embedding-attention.md`
7. `deep-learning/transformer-llm.md`
8. `llm-engineering/llm-apps.md`
9. `llm-engineering/mcp-agent-skill.md`

## 学习方式

先读概念，再看公式，最后用小实验验证。比喻只用于建立直觉。
