# 数学与数据表示

## 总比喻：一座会学习的工厂

把机器学习模型想成一座工厂：

- 数据是送进工厂的原材料
- 特征是原材料上的标签
- 模型是工厂里的加工机器
- 参数是机器上的旋钮和齿轮位置
- 预测是机器加工后的产品
- 损失是质检员打出的扣分
- 梯度告诉工人应该拧哪个旋钮、往哪个方向拧

## 函数：加工规则

正式写法：

```text
y = f(x)
```

比喻：把苹果放进榨汁机，机器按照规则输出果汁。`x` 是苹果，`f` 是榨汁机，`y` 是果汁。

机器学习模型也是函数，只是它内部的旋钮会通过数据自动调整。

## 特征：原材料标签

一套房子可以写成：

```text
[面积, 房间数, 楼层, 房龄]
```

比喻：房子进入工厂时，身上贴着几张标签。模型不直接看“房子”这个概念，而是读取这些数字标签。

## 向量：一排有顺序的标签

向量就是有顺序的数字集合：

```text
x = [面积, 房间数, 楼层, 房龄]
```

比喻：向量像一张货物登记卡。卡片上每个位置都有约定用途，整张卡共同描述一个对象。

向量有多少个数字，就有多少个维度。大语言模型中的 Token 也会变成高维向量，但每一维通常没有一个固定的人类名称，它们像许多隐藏刻度共同描述 Token。

## 矩阵：一整车货物的登记表

矩阵可以看成多条向量排成的表格。比喻：一条货物登记卡是向量，整车货物的清单就是矩阵。矩阵运算让工厂一次加工很多货物。

## 距离：两件货物有多像

```text
d(x, y) = sqrt((x1-y1)^2 + (x2-y2)^2 + ...)
```

比喻：把每个对象放到一张地图上，距离越近，通常表示它们越相似。K-means 和 K 近邻都用到了这个直觉。

余弦相似度：

```text
cos(x, y) = (x · y) / (||x|| ||y||)
```

比喻：不太在意两支箭有多长，只看它们指向的方向是否接近。文本向量检索常使用这种相似度。

## 概率：模型的下注比例

```text
正常邮件：0.15
垃圾邮件：0.85
```

比喻：模型像下注者，不是说自己绝对正确，而是在不同答案上分配信心。

## 损失函数：质检扣分

预测值和正确答案相差越大，损失通常越大。比喻：质检员不只说“好”或“坏”，而是给机器一个具体扣分。训练的目标就是让总扣分越来越少。

## 导数和梯度：返工指示牌

导数表示某个量变化时另一个量变化得多快。梯度是很多参数的导数集合。

比喻：质检员发现产品不合格，梯度告诉工人哪个齿轮影响最大，以及每个齿轮应该往哪个方向调整。

```text
新参数 = 旧参数 - 学习率 × 梯度
```

学习率像每次拧旋钮的幅度。太大容易拧过头，太小则改得很慢。

## 最低数学目标

- 看懂函数、参数和变量
- 知道向量的维度、矩阵的形状
- 理解距离和相似度
- 理解概率是信心分配
- 理解损失是错误程度
- 理解梯度用于降低损失
