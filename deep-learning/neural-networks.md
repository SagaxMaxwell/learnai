# 神经网络基础

## 总比喻：多层筛选器组成的加工流水线

神经网络像一条流水线。每一层筛选器都会把原材料重新整理，再交给下一层。

图像中可能是：

```text
边缘 → 形状 → 局部结构 → 物体
```

语言中可能是：

```text
Token关系 → 词组关系 → 句法关系 → 语义模式
```

## 神经元

```text
z = w1x1 + w2x2 + ... + b
y = activation(z)
```

比喻：一个质检员给不同线索加权打分，再用激活函数决定“是否通过、通过多少”。

## 激活函数：弯道开关

如果每层都只是直线加法，多层叠加后仍然像一个大直尺，表达不了复杂规律。

激活函数给流水线加入弯道和开关，使网络能够表示非线性关系。常见的有 ReLU、Sigmoid、Tanh。

## 前向传播

输入从第一层流到最后一层，得到预测结果。这像流水线从原材料一直加工到成品。

## 反向传播

模型先看成品被扣了多少分，再把责任从最后一层向前追溯，计算每个参数对错误的影响。

比喻：如果最终蛋糕不好吃，质检员沿流水线倒查：是烤箱温度、面粉比例，还是搅拌时间导致问题。

## 训练循环

```text
输入 → 前向传播 → 计算损失 → 反向传播 → 更新参数 → 重复
```

这就是神经网络通过错误逐渐改进的基本机制。

## 关键参数

- Batch：一次送进流水线的样本数量
- Epoch：完整看过训练集一次
- 学习率：每次调整旋钮的步长
- 优化器：具体的调参方法
- Dropout / Weight decay：帮助避免只背练习题
